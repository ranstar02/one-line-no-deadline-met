A tiny deterministic Python program (stdlib only, no network, no randomness) that writes one original single-line joke excusing a missed deadline. The joke flips the blame: the deadline missed *me*, and it never even apologized. The program validates the line (non-blank, exactly one line, 1–200 characters), writes it to `/output/entry.txt` (falling back to `./output/entry.txt`), reads it back, and verifies the file holds exactly the line before printing the character count and the line itself.

## Run it

```sh
python3 main.py
```
